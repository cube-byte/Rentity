# Rentify

Sistema web para gestión de alquiler de vehículos desarrollado con JavaScript - Java - Kotlin - MySQL

---

## Tecnologías utilizadas

**Data Base**
- MySQL

**Back-End**
- Java / Spring Boot
- Kotlin

**Font-End**
- HTML, CSS, JavaScript
- TypeScript
